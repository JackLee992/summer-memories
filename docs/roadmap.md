# 路线图（Roadmap）

## 当前路线：PC 小队策略冒险动作（2026-09-20）

依据 [ADR-0003](decisions/0003-pc-action-adventure.md) 与 [小队 Demo 方案](st-squad-demo.md)，当前优先级如下；旧 M0–M5 不再作为执行顺序。

| 阶段 | 交付 | 验收 |
|---|---|---|
| S0–S2 机制与流程 | 已接入小队、复制、携带、回溯、调查、俯瞰与存档 | 实际构建和回归见验收记录；人工手感继续迭代 |
| v02 基础操作与美术 | 跳跃、独立闪避、轻重击/武器，开局战斗；AI 头像/主视觉、Blender 网格、阴影、水面 | 逐项实测键鼠入口、物理跳跃、战斗、UI 和导入模型 |
| v03 战斗配合与人物动作 | 三类出招、架势/收招/协同追击、肘膝躯干和法线修正 | 80 项回归通过；人物与游戏性尚未获用户认可，详见 [阶段记录](squad-verification-2026-09-20.md) |
| S3 动画与场景样板 | Seedance 参考→姿态重建→清理重定向；完整基础动作与更完整海岛场景 | 保持判定、根骨位移、脚底与中断一致；尚未完成 |
| S4 品质切片 | 目标 15–20 分钟、手柄、Windows、分阶段 Boss、性能及剧情回归 | 需人工盲测与指定目标硬件的性能证据 |

《黑神话》用于品质参考；内容以所有者指定的《夏日重现》原型为准。Windows x64 是建议的对外 PC 目标，本机 Mac 作开发回归；Android 扩展、开放世界与全作章节生产后置。当前尚无目标 PC 性能基线、确认的制作团队或预算，不承诺未经测算的全作日期。

## M1 — 第一章《影外微阴》（v0.2）📋

> 形态决策见 ADR-0002：章节制**海岛枢纽半沙盒**（自由探索 + NPC 日程 + 线索/道具收集），
> 不做开放世界与农场经营闭环；开源只做组件级复用（Yarn Spinner/MIT 对话、Unity 2D Tilemap）。

- 新增 `SummerMemories.Explore` 程序集：枢纽地图（Tilemap 顶视角、碰撞、场景切换、交互点）
- NPC 日程系统（周目内日期/时段/天气驱动位置与对话），Yarn Spinner（MIT）承载自由对话与支线
- 世界状态 + 回潮"继承（TIPS/锚点/羁绊）/重置（物质/NPC/当日事件）"规则，存档扩展并测杀进程续档
- v0.1 序章/教学/首战接入枢纽入口，胜利后回到枢纽而非直接结束
- 村内自由探索（白天枢纽 + 点位移动）、海灯祭筹备
- 熟人辨伪玩法（铜镜/倒影/火眼金睛指认罔两；误判有后果）
- 回潮"弄巧成拙"事件链（喜剧 + 信任度系统）
- 记忆磨损 UI 首版（阿娃立绘褪色/名字乱码）
- 潜水日志收集线开启
- 音效与环境音、原创主题动机
- 第二个战斗关卡（堤口夜袭，引入蜮远程单位）
