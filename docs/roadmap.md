# 路线图（Roadmap）

> 原则：叙事驱动，每个里程碑都必须"从头到尾可玩、有一段完整情绪"。
> 标记：✅ 已完成（MVP 代码/数据层）　🚧 进行中　📋 规划中

## M0 — Android MVP（v0.1）🚧

- ✅ Unity 6 工程骨架、五个运行时程序集 + Editor 构建脚本
- ✅ 自举启动（无需手工场景）、标题页、横屏、程序化 uGUI
- ✅ ADV 系统：背景/立绘/对白/旁白/打字机/选项/标志位/历史/跳过
- ✅ 外层回潮（锚点、回潮计数、存档）与教学
- ✅ 网格战棋：移动/攻击/桃橛定身/待机/敌方 AI 与意图预告/胜负
- ✅ 火眼金睛（每回合窥意图）、救命毫毛（每场 3 次快照回溯）
- ✅ 《山海异闻》跨回潮继承
- ✅ 序章 + 回潮教学 + 海堤战（原创剧情与数据）
- ✅ 原创 AI 原型美术（4 背景 + 5 立绘 + 图标）
- ✅ GDD、设定集、架构、版权、环境、ADR、协作契约
- 🚧 本机安装 Unity 编辑器、实际编译、出 ARM64 APK、真机/模拟器截图验证
- 🚧 首次 git 提交并推送远端
- 📋 `.meta` 文件在编辑器首次导入后补提交

## M1 — 第一章《影外微阴》（v0.2）📋

- 村内自由探索（白天 ADV + 点位移动）、海灯祭筹备
- 熟人辨伪玩法（铜镜/倒影/火眼金睛指认罔两；误判有后果）
- 回潮"弄巧成拙"事件链（喜剧 + 信任度系统）
- 记忆磨损 UI 首版（阿娃立绘褪色/名字乱码）
- 潜水日志收集线开启
- 音效与环境音、原创主题动机
- 第二个战斗关卡（堤口夜袭，引入蜮远程单位）

## M2 — 第二章《潮鸣洞》（v0.3）📋

- 潮鸣洞迷宫探索、摩崖钓鳌壁画（员峤真相碎片）
- 沉船墓群、无启氏不腐尸（猎奇支线）
- 龙宫旧墟入口、巡海夜叉统领 BOSS 战
- 七十二变（初阶：变鱼潜水）解锁
- 巨鳌骨架/倒悬古城奇观场景

## M3 — 第三章《誓鸟填海》（v0.4）📋

- 阿娃溺亡真相记忆碎片（后悔主线：冷战、未赴约、主动赴死）
- 精卫身份悬念推进、龙女族规线
- 身外身法（分身）解锁、护送精卫衔石战
- 情感高潮章节（无大 BOSS，重剧情）

## M4 — 第四章《海灯祭 · 百鬼夜行》（v0.5）📋

- 七月十五夜：信任账本清算、全村辨伪终局
- 民俗异物群像（走无常、阴差借身、蜮群）
- 精卫身份揭晓、猰貐登场（复活即诅咒）
- 幕后钓鳌客线收束

## M5 — 终章《归墟》（v1.0）📋

- 海眼下潜、生死簿水册、定海神针、六耳（石头自己的脸）
- 金箍抉择、最终战（全神通战棋）
- 三个结局：A 放灯（凡人治愈）/ B 金箍（大圣式悲情）/ C 钓鳌（黑化）
- 二周目彩蛋、真结局记忆锚点收集

## 平台路线

| 平台 | 阶段 | 前置 |
|---|---|---|
| Android（ARM64，8.0+） | M0 起 | Unity Android 模块（OpenJDK17/SDK/NDK r23b） |
| iOS | M2 后评估 | Xcode、Apple Developer Program（上架） |
| Nintendo Switch / Switch 2 | 商业化立项后 | 任天堂开发者授权、Unity Pro、Windows 10 Pro 构建机、lotcheck |

## 商业化前置（与内容并行）

- AI 原型美术/音频全部替换为签约原创资产，留存授权链
- 字体/音乐商用授权、名称商标查重
- 软著、版号（中国大陆）、隐私政策、年龄分级
- 存档云同步、设置（音量/文字速度/多语言）、崩溃上报
