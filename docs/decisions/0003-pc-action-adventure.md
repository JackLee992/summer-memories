# ADR 0003：PC 小队策略冒险动作 Demo

- 日期：2026-09-20
- 状态：**方向已由所有者明确；玩法细则为首版实施方案**。
- 所有者决定：第三人称、PC 优先；组队策略冒险动作；先以《夏日重现》人物与剧情背景制作 Demo，保留影子、头发、原始人物、贝壳、回溯；美术可用 AI 图转 3D，音乐可用 AI 或程序生成，动作用武术影视作参考。
- 替代范围：ADR-0002 的 2D Tilemap / 战棋主玩法 / Android 优先路线。旧神话版继续作为历史内容与回归样例。

## 产品方向

先完成一段 15–20 分钟的**调查、组队、遭遇、回溯、利用情报改变结果**闭环。第三人称实时操作结合队友指令与战术决策；单人指挥小队是当前默认，不把联机作为首版依赖。

《黑神话：悟空》作为角色动作、命中反馈、镜头、场景细节和演出完成度的质量参照。当前内容方向以《夏日重现》为准，不能再让石头、阿娃、桃橛和夜叉自动替代已确认的原作人物与要素。

## 内容与玩法

- 核心人物：网代慎平、小舟潮、南方日鹤、南方龙之介；三具身体，日鹤/龙之介切换意识；小舟澪作为关键剧情人物；切换角色、潮的头发能力、扫描与变成已扫描物品均为首版必做。
- 保留五项：影子、头发、原作人物、贝壳、回溯。头发不再改成「三根毫毛」；贝壳不是普通金币；影子也不再以夜叉/罔两替换。
- 原作身份、人物关系与既定事件先核对来源；游戏对白、提示和任务文本重新撰写。头发/贝壳的具体超自然规则未核实时不杜撰为原作设定。
- 角色切换、跟随/守位/集火、协作窗口与情报继承构成策略层。即时动作服务于这些决策。
- 原作开局与可同行的队伍阶段有时间差，先制作「返岛调查叙事段」与「慎平＋潮的小队验证段」；后者明确标注玩法改编，不宣称两人从葬礼开局就在并肩战斗。

详细事件顺序、快照边界、资产制作和验收见 [小队 Demo 方案](../st-squad-demo.md)。

## 技术约束

继续使用 Unity 6000.0.83f1、C#、JSON 数据驱动、uGUI + UIFactory、1920×1080 横屏和程序化 Boot。依赖方向向内：

```text
Core ← ADV / Battle / Loop / Action3D ← App ← Editor
```

App 持有模式、队伍、检查点与持久化的调度权；玩法模块不按对象名销毁 App。新旧内容使用不同 id 前缀和存档槽，旧存档路径与坏档隔离规则保持。战棋规则只作为历史回归和快照设计参考。

正式图片仍按既有 Art 路径组织。程序音频置于 `Resources/Audio/Prototype/`；3D 模型先在制作目录保存，运行时导入路径与角色 Prefab 规范在接入时单独落档。渲染建议先做 Unity 6 URP 小样与打包验证；本次没有安装渲染包或更换管线。

## 制作决策

1. AI 角色参考图与三视图 → 图生 3D / 建模 → 重拓扑与 UV → PBR 贴图 → 骨架蒙皮 → 动画 → Unity。
2. AI 音乐草稿或原创程序配乐；程序制作交互音效。保留生成方法、提示词、版本、来源和导出参数。
3. 武术影视拆解重心、步法、攻防节奏；通过自录、可用动捕素材或经清理的视频转动作生成动画，再重定向与游戏化调时。
4. 单张漂亮图片、自动生成网格或未经清理的视频动捕不计作「游戏资产已完成」。

## 完成门槛

- 三具身体切换与指令可用，角色身份/队伍状态不会在回溯时串位。
- 调查一条影子相关线索、查看头发与贝壳相关内容、遭遇一次威胁、保留情报回溯、改变队伍策略、完成救援或撤离；有可达的成功与失败结果。
- 快照覆盖全队位置/生命/动作/冷却、敌人、事件、检查点；跨轮记忆单独保存。
- AI 图、模型、声音、动作各有一项真正进入 Unity 的样板，且通过运行时验收。
- PC 1080p / 60 fps 是目标，未测得最低配置；先在本机 Mac 回归，再验证 Windows x64 包与目标机。
- 20 次连续回溯不积累异常，30/60/120 fps 下输入与判定一致。
