# ADR-0004：基于现有内容的 2.5D 试作

状态：2026-09-20 所有者确认“以现在的内容为基础，尝试一版 2.5D”。此前已确认简单 3D 场景、2D 人物、俯视镜头与可暂停下令的小队策略冒险方向。

## 决策

继续 Unity 6000.0.83f1，复用现有小队/敌人、战斗规则、复制、调查、回溯、俯瞰与存档结构。新增固定正交斜俯视镜头与面向镜头的角色精灵，保留真实场景碰撞和遮挡。2.5D 使用单独构建和 `st_demo25d` 存档，方便与已保存的 3D 原型比较。

新交互：Space 暂停/恢复战术时间；暂停中 1/2/3 或点击人物选队员，右键地面安排移动，右键敌人安排攻击，E/K 将该队员对目标的下一次动作设为技能/重击。每位队员一条可替换指令，显示路径或目标线，恢复后执行。WASD 仍可直接操作当前角色，手动移动取消该角色指令；Alt 跳跃、Ctrl 闪避，原扫描/变形/回溯键继续使用。4/5/6 指令清除个人部署，重新设置全队行为。

规划暂停要冻结战斗、扫描、冷却和分支时间；不冻结菜单鼠标、选人和镜头显示。恢复、回溯、重新开始与胜败时正确清理规划状态。给不可通行地点下令要明确拒绝，不把路径穿墙当作成功。

## 复用与新增

| 项目 | 现有实现 | 决策 |
|---|---|---|
| 玩法与剧情 | SquadSession3D、Actor、Enemy、JSON、OverlookArchive | 直接复用，保持既有身份与状态归属 |
| 人物 | SquadBody 的姿态接口 | 增加 2D 展示分支，生成精灵并保留制作记录 |
| 镜头 | CameraRig3D | 新增固定正交配置，锁定不改变观察轴 |
| 暂停下令 | 全队 Follow/Hold/Focus，无逐人指令 | 新增队员选择、可视路线、移动/攻击/技能指令与可通行路径检测；为已确认试作所需 |
| UI | 代码生成 uGUI | 沿用 UIFactory；新增战术条与提示，不引入框架或 Prefab |

此版验证视觉形式与策略操作是否值得继续，不声明已完成完整八方向逐帧动画、15–20 分钟关卡或正式品质验收。
