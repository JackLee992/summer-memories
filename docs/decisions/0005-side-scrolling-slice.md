# ADR-0005：横版 2D 小关卡

2026-09-20，所有者体验 2.5D 后认为仍与成熟游戏差距明显，提议参考《ICEY》的横版形式，并明确选择“切换横版 2D，先做完整小关卡”。最新方向覆盖 ADR-0004 的继续扩展计划；保留 2.5D 试作和旧 3D 基线用于比较。Unity 6000.0.83f1 不变，不使用《ICEY》的角色、关卡、音乐或提取素材。

## 范围

目标是约五分钟的可玩小关卡，实际时长须试玩记录，不因地图长度或代码检查而宣称完成。玩法集中于切人协同、复制潜入、回溯情报：街口扫描和装备 → 潮化为石块通过仓库矮道 → 贝壳调查与开闸 → 可选手表潜入 → 束缚换人追击和重锤破防 → 限时破坏核心救澪；失败回到锚点，保留经历与信息。

横版采用当前角色在场、三人可切换的队伍方式。日鹤与龙之介仍为同一身体，潮手表形态附着慎平，可提供发束支援。此版不保留俯视暂停部署/自由寻路操作，完整俯瞰仍展示所有亲历分支的时间、事件和路线。

## 技术与资源

- `Action3D/Side2D` 目录是现有运行时程序集内的独立横版模块；依赖继续只指向 Core。`SideSession` 负责可确定步进的平面碰撞/战斗/事件，`SideWorld` 负责渲染；App 负责输入、UI、存档。
- 内容写 `Battles/st_side2d.json` 与现有 Localization，界面沿用 uGUI/UIFactory。
- 独立包 `Builds/SummerTimeSide2D.app`，独立槽 `st_side2d`，动态 Boot 场景。
- AI 动作图表必须人工检查分格和语义，再经本地 BiRefNet 抠图。拒绝把自动生成的十二格布局当作已验证连续动画；实际使用的原图区域、脚底锚点与重复帧有加工记录。
- 日鹤美术约束：长柄（约身高 75%）、适中的双面钢锤头、扛肩姿势；避免小工匠锤和夸张巨型锤。
- 验收分别记录：代码回归、画面检查、实际操作；不把前两项当作好玩的证明。
