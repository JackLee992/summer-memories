# Demo 资产管线：AI 图、3D、动作与声音

2026-09-20。当前用于《夏日重现》小队策略动作原型。所有状态以实际文件和 Unity 验收为准。

|---|---|---|
| 1 | 慎平、潮、日鹤 | 各一张角色定稿、正/侧/背三视图、头部和手部细节、比例标尺 |

| 2 | 海边小路和民居入口 | 30 米可玩环境、模块化路面/围栏/灯/石/植被、水面与远景 |

## 2. AI 图到模型

1. 先锁定一张角色主参考，再用同一参考生成正、侧、背视图。不能把三张互相矛盾的生成图直接送入建模。
2. 单角色、全身、正交感、A-pose、中性光、素灰背景；视图等高、服装层次和配件一致。姿势、道具位置和遮挡必须适合建模。
3. 图生 3D 或人工建模先生成低成本样体；检查背面、手指、衣物内层、左右对称及尺寸。自动网格不是成品。
4. 清理网格并重拓扑，处理关节边流、UV、法线、贴图烘焙与材质分区。头发分为近景发束或发片与远景 LOD，避免整头高成本动态模拟。
5. 骨骼/蒙皮/基础表情，完成转头、抬臂、下蹲、跑、闪避测试后再扩展动画。
6. FBX/材质进 Unity，统一米制、朝向、导入比例、骨架 Avatar 与纹理设置；资源 GUID 随 `.meta` 一起保存。
7. 以实际游戏镜头检查轮廓、阴影、变形、穿模和帧时间，确定面数、贴图尺寸、材质数量和 LOD 预算。先测目标机，不空口规定“百万面才是高画质”。

### 可直接用于首轮出图的提示词规格

角色参考模板：

> 用途：第三人称动作游戏角色建模参考。人物：{网代慎平 / 小舟潮}，来自《夏日重现》。保持其可辨认身份与少年感，服装和发型以经过核对的统一角色参考为准。单人全身 A-pose，正面、侧面、背面等高排列，中性灰背景，柔和均匀工作室光，近似正交视角，无戏剧透视，无强阴影，无场景遮挡。关节和鞋底清晰；三视图的脸型、发束、服装接缝和配件完全一致。风格化 PBR 游戏角色参考，无标题、水印、标志或其他人物。

贝壳参考模板：

> 用途：关键调查道具的建模与材质参考。单枚海边贝壳，外形以确认后的剧情道具参考为准；正面、背面、侧面、开口与表面微距视图，统一尺度和中性照明。展示天然纹理、厚度、边缘磨损，不加入未经设定的符文、宝石或魔法机关。灰色背景，无文字和水印。

## 3. 武术影视参考到游戏动作

参考片段用于分析重心、步法、肩胯发力、接触点、节奏和收招。每个动作记录来源、时间范围、动作目的和可借鉴的运动规律；不把影视截图/剪辑当作最终游戏动画资产。

优先采集自录表演或可用的动捕素材。视频转动作是可选辅助：完整身体、尽量固定机位、少遮挡、无切镜、可见脚部和地面；多机位优于单目。剪辑影片的透视、遮挡、镜头运动和不可见关节会产生重建误差。

流程：参考分析 → 分解表演 → 采集或视频重建 → 清理脚滑/抖动/骨长漂移 → 重定向到目标骨架 → Root Motion/原地动作处理 → 游戏内调时 → 判定和镜头验收。

| 动作类别 | 首批数量建议 | 游戏验收重点 |
|---|---:|---|
| 待机、走、跑、转向、急停 | 每角色 6–8 段 | 速度与脚步一致，切换无漂移 |
| 攻击/配合 | 每角色 3–4 段 | 前摇可读、击中时刻和碰撞一致、收招可惩罚 |
| 闪避/撤步/受击 | 每角色 5–7 段 | 位移、无敌窗口、受击方向与操作响应一致 |
| 调查、拾取、指令 | 共享 3–4 段后按角色调整 | 手与物件接触、不穿模 |
| 倒下、回溯恢复 | 每角色 2–3 段 | 动作可以中断，回溯后不残留状态 |

慎平以观察、闪避和普通人的动作逻辑为主；潮的超常动作需要专门设计。真实感不等于不可打断的长前摇。头发视觉用骨骼/约束表现，实际命中使用稳定的攻击数据与碰撞轨迹。

尚未取得动作源、未做动捕或视频重建。先验收每角色一套基础动作再决定是否扩建完整动作库。

## 4. 音乐与程序音效

- AI 音乐：用情绪、乐器、速度、动态层次描述目标；生成探索/威胁/战斗版本或 stems，保存提示词、模型、生成日期和版本。当前未调用音乐生成服务。
- 程序音乐：可复现的音高、和弦、节奏与合成器参数，适合首版气氛草稿。
- 程序音效：影子显形、回溯、发束挥动、贝壳拾取；结合真实空间的混响和距离衰减再调音。
- 运行时分组：Music / Ambience / SFX / UI；短声音预载，音乐按平台采样决定压缩与加载方式；不要在主线程临时生成整段音乐。

本轮原创程序资产（44.1 kHz、16-bit、立体声 PCM WAV）：

| Resources key | 时长 | 用途 |
|---|---:|---|
| `Audio/Prototype/st_ambient_v01` | 32 秒 | 安静海边、略带不安的合成配乐草稿 |
| `Audio/Prototype/st_shadow_reveal_v01` | 1.15 秒 | 影子显形 |
| `Audio/Prototype/st_rewind_v01` | 2.2 秒 | 时间回溯 |
| `Audio/Prototype/st_hair_bind_v01` | 0.65 秒 | 发束束缚与打断提示 |
| `Audio/Prototype/st_shell_pickup_v01` | 1.4 秒 | 贝壳线索记录 |

生成器：`python3 tools/generate_demo_audio.py`。仅使用 Python 标准库和原创数学合成，不含第三方采样或动画原声。所有文件为草稿；配乐两端有淡出/淡入，**不是无缝循环**，后续循环版需单独制作。已与小队版环境、影子显形、发束、拾取和回溯事件相连，混音仍是原型。

验收：峰值留余量、无数字削波、检查首尾样本和突变、耳听音色与混音遮蔽；进行实际耳机/音箱试听及游戏内混音后，才可写成最终音效。程序测量报告在 `Builds/audio-audit/st-demo-audio.json`。

## 5. 追溯与交付

每个资产记录 id、角色/道具身份、源参考、生成提示词或脚本、版本、后处理、导出设置、适用阶段和导入 `.meta`。原作人物内容、AI 中间产物、原创程序音频、外部动作源分别注明来源，不能继承旧项目的“全部原创”总声明。

AI 生成是原型制作方法；正式发行的授权与项目既有商业化前资产政策仍需按实际素材逐项落实。本次没有引入官方模型、截图、动画剪辑、音乐或演员配音。
