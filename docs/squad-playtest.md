# 小队原型试玩与验收

运行包：`Builds/SummerTimeSquad.app`（Mac Apple Silicon，键鼠）。Unity 6000.0.83f1，菜单 `夏日回忆/Build/Mac 小队动作原型 (.app)` 或 `bash tools/build_squad_mac.sh` 重建。Windows 构建未验证。

## 主路径

1. 标题选择「直接进入试玩」立即行动，或「查看序章」阅读对白。前方 F 拾起钢管，Space 跳过低台，观察巡游影子的金色横扫范围，空格跳过或 Ctrl 撤出，然后在收招时反击。
2. WASD 沿海边主路前行；右键拖动镜头。Tab 或 1 / 2 / 3 切换慎平、潮、日鹤。V 在日鹤身体内切换龙之介意识。
3. 潮站定后按 F 扫描右侧木箱、左侧石块，B 打开复制形态目录。靠近慎平按 F 可扫描手表；扫描不消耗物件。
4. 调查主路金色路标下的影迹。可选探索：潮按 X 化为石块，从左侧矮道的南侧入口进入，靠近贝壳按 F。沿原路退出后按 G 恢复人形。
5. 可调查右侧发束。按 C 变成扫描过的手表，由慎平携带；按 2 在安全位置让潮现身。
6. 到红色路标按 F，全队集合恢复生命与体力，建立战前锚点。
7. 先观察敌人：红色长条为突进，金色扇形为可跳过横扫；守路者正面减伤，K 重击破势或潮 E 束缚后换人追击。J / 左键轻击三段连击，K 重击，Space 跳跃，Ctrl 闪避，Q 锁定，T 切换慎平的钢管/徒手。潮用 E 发束打断并束缚；日鹤按 V 后龙之介用 E 近身压制。4 跟随、5 守位、6 集火。倒下同伴可靠近后 F 扶起；慎平倒下进入失败界面。
8. R 回溯全队。头发、贝壳、影迹的已知情报保留，物理状态恢复到锚点。战前已扫描目录恢复，未入锚点的扫描不保留。
9. 清理三名影子（含耐久更高的守路者），到尽头青色路标按 F，与澪会合进入胜利界面。
10. 随时在行动中按 M 俯瞰，选择已经历的时间分支、事件与地图位置；滚轮浏览列表。M / Esc 返回。暂停菜单可查看情报。

## 状态与存档语义

- `st_demo` 与原版 `auto` 分开。存档仍位于 `Application.persistentDataPath/saves/{slot}.json`；原子替换，坏档改名保留 `.broken-<ticks>`。
- 存档保存最近锚点、对白进度、已知情报、循环次数、所有亲历的分支事件/地图记录。继续锚点时保存旧分支并新建一条；不声称精确回到退出前每一帧。
- 日鹤/龙之介共用身体、生命、位置、体力和技能冷却。潮的木箱、石块、手表共用潮的身体状态。手表附着时不独立寻路，不成为独立敌方目标。
- 低矮空间禁止强制现身或切离潮。变形计时到期时若不能安全现身，会维持形态直到离开。手表保持附着，直到选择潮现身或回溯。
- 俯瞰是对经历的记录，不是任意跳转过去的存档编辑器，不生成未经历剧情。以分支内游戏时间记录事件，不声称已有完整动画日历模拟。

## 自动验证

```bash
bash tools/build_squad_mac.sh
Builds/SummerTimeSquad.app/Contents/MacOS/SummerMemories \
  -batchmode -nographics --squad-smoke \
  --squad-report "$PWD/Builds/squad-smoke.json" \
  -logFile "$PWD/Builds/squad-smoke.log"
```

测试驱动实际运行时 API、CharacterController 碰撞、敌方 AI、攻击计时与存档；只为布置测试场景直接改变位置/伤害。测试使用随机 `st_smoke_*` / `st_test_*` 槽，不写玩家 `st_demo`。不依靠直接清空敌方生命来冒充战斗胜利。

当前执行结果与视觉检查结论见交付时的 `docs/squad-verification-2026-09-20.md`。自动脚本不等同于人类对手感和难度的盲测。

## 当前边界

这是机制原型，目标是验证探险、信息差和队友救援体验。v02 已导入即梦角色头像/海岛主视觉、Blender 角色与房屋/渔船，加入水面、阴影、轨迹、伤害数字与程序战斗声音。v03 重做人物比例、弧形发片与肘膝/躯干动作，加入攻击范围预告、架势破防、束缚后的换人双倍追击、精准闪避反击，以及队友躲避/绕侧。程序姿态、局部避障 AI 仍需打磨；尚未完成一致三视图、正式骨骼动画、Seedance 视频生成、姿态提取、正式配音或 Boss 多阶段行为。

现有音乐/七音效已接到事件；配乐为带淡入淡出的 32 秒草稿循环，尚未制作无缝音乐分层。15–20 分钟是后续切片目标，当前没有该时长与 AAA 品质的验收结论。当前调查开局与潮同行玩法段通过明示过渡分开，不是完整逐集剧情复刻。
