## 核心体验与人物

探索异常 → 记录线索 → 扫描复制与小队部署 → 实时遭遇战 → 成功会合或回溯改策。新增系统服务于探险、信息差带来的惊奇与队友互助。

| 网代慎平 | 调查、指挥、跳跃、闪避、徒手/钢管轻重击、俯瞰 | `st_shinpei`，他的倒下触发失败 |
| 小舟潮 | 发束近战、头发远程束缚、扫描和物品变形 | `st_ushio`，变形不改变生命归属 |

## 当前关卡

- 标题可直接进入动作试玩，也可先阅读返岛介绍。调查开局与能够和潮同行的阶段以明示的玩法衔接分开，未宣称从葬礼开始就可同行。
- 开局可以拾起钢管，跳过低台，和一名巡游影子战斗；不需要先跑完整条空路才能试操作。
- 主路异常影迹是进入后续遭遇战的条件；左侧贝壳矮道是可选的石块变形探索，右侧可调查发束。
- 红色路标集合后进入三名影子的遭遇战，其中守路者耐久较高。所有敌人死亡后到青色路标与澪会合。
- 三类敌人分别使用直线突进、扇形横扫、正面守势。地面范围预告与实际伤害判定共用方向和攻击类型；突进可侧闪、横扫可起跳，敌人收招期间承受 1.35 倍伤害。
- 守路者正面轻击只承受 30% 伤害，重击削减架势，绕后绕过防御；架势清空后出现破绽。潮发束可直接束缚，随后由另一队员命中可消耗一次双倍追击机会，同一角色不能触发。
- 闪避前 0.24 秒免伤，前 0.16 秒避开实际命中时返还 18 体力，并强化 2.5 秒内的下一次普通/重击；闪避后段可被击中。不是全程无敌或纯被动加伤。
- 攻击分蓄力、命中、收招，带向前垫步、轻重击不同顿帧与轨迹；命中后可在收招中换人。换人保留锁定，镜头平滑交接。
- 集火队友优先跟随锁定目标，会观察前摇避让、从两侧接敌，潮会束缚、日鹤会重击守势。守位继续明确停止主动行动。局部避障仍非完整导航。
- 武器拾取与装备进入快照。

## 复制与携带

由潮对近距离可扫描目标按 F，站定并保持视线完成 1 秒扫描；受伤、移动、出招或切人会中断。B 打开可见形态目录，也可使用 Z / X / C。

- 木箱：低速移动、静止伪装；移动会暴露。
- 石块：缩小控制器碰撞，可通过贝壳矮道。碰撞使用适配的胶囊近似，而非复杂模型三角网格。人形空间不足时拒绝现身与切人，计时到期也不会强行塞进天花板。
- 手表：扫描慎平身上的手表后可附着携带，自动切回慎平。潮不再独立寻路或成为独立目标。按 2 在附近安全位置现身；潮保留自己的生命、扫描目录和冷却。

## 回溯、俯瞰与存档

锚点分别位于调查起点与后续战斗前。回溯停止动作，取消变形/携带，恢复队员与敌人的位置、生命、冷却、扫描目录、物理拾取与命令。已知情报、循环计数、俯瞰档案保留。

M 进入俯瞰：所有亲历分支列表、分支内时间与事件、探索过的地图路径相互联动。点击事件可查看坐标与当时队员快照。旧分支不会因回溯被删除，尚未经历的内容不显示。继续存档回到锚点时记录一次新分支；不提供任意跳转历史事件的能力。

存档使用独立 `st_demo`，仍在固定 `persistentDataPath/saves`。Core 负责原子写入与坏档隔离；App 用现有 flag 容器存储检查点和俯瞰 JSON，不让 Core 依赖动作模块。日鹤/龙之介和潮的所有形态都不会复制生命池。

## 实现边界

`Core ← ADV / Battle / Loop / Action3D ← App ← Editor`。新增机制位于 `Action3D/Squad`，不继续叠加旧单人控制器。App 的唯一 Bootstrap 在创建前选择小队、旧战棋或旧海堤模式。

`SquadConfig` 读取独立的 `Battles/st_squad_demo.json`。角色、技能、场景碰撞体、任务、出生点与文案引用由 JSON 定义；剧情、情报、本地化继续使用各自 Resources 目录。UI 由 UIFactory/uGUI 创建。当前俯瞰与菜单暂停以统一 Session.Paused 控制游戏逻辑。

美术包括三位角色的 Blender 原创网格、房屋与渔船、方向光与阴影、水面着色器，以及即梦生成的头像/主视觉。记录见 [生成清单](art/st-v02-generation.json)。这些仍是可替换的原型资产；动画依然是命名关节的程序姿态，不称为已完成动捕。Seedance 参考制作包见 [动作说明](motion/seedance-reference-pack.md)。

下一阶段重点：连招/闪避/镜头的人工手感迭代、真正的骨骼动画、敌人分阶段行为、可持续的导航、逐段剧情核对、Windows 和手柄验证。首轮审计的历史证据保留在 [审计报告](demo-audit-2026-09-20.md)，不将该报告的旧状态当作当前实现。
