# Seedance 动作参考包 v01

2026-09-20，所有者确认使用 Seedance 生成武术影视风格的动作参考，再进入游戏动画制作。**本文件是制作清单和可执行提示词；本轮尚未调用 Seedance、生成视频或提取骨骼。**

## 统一采集镜头

每条单独生成：6 秒，24 fps，16:9，固定机位，完整身体始终在画面内，双脚与地面清楚可见，三分之二侧视。浅灰无纹理背景、均匀摄影棚光、贴身练功服；不切镜，不推拉摇移，无运动模糊和遮挡，无第二个人。头尾各留 1 秒稳定站姿，动作结束回到清楚的重心支撑状态。每条只含一个动作，不把连招和不同机位合并。

先用无角色服装的动作人偶解决运动规律；之后重定向到慎平、潮、日鹤的游戏骨架。影视用于分析步法、肩胯传力、支撑脚和收招节奏，不把镜头运动造成的位移误认作根骨运动。

## 从参考到运行时

1. 生成后逐帧验收：骨长不漂移、关节数量正确、手脚持续可见、脚下接触连续。失败的视频退回重生，不用后续算法掩盖结构错误。
2. 提取人体姿态，重建骨架。单目结果有深度歧义，需人工校正髋部、脚底和武器约束。潮的头发不作为人体姿态估计骨架的一部分。
3. 重定向到目标 Avatar，统一米制、朝向与参考姿势；分别导出原地版与带位移版。
4. 清理抖动、脚滑和根骨漂移；在 Unity 用攻击前摇、有效帧、收招、取消窗口驱动动作。
5. 本原型以代码动作计时判定；替换动画时命中逻辑保持明确时间数据，不依赖不稳定的视觉估计。多人、变形和回溯都会中断动画，禁止遗留协程继续命中。
