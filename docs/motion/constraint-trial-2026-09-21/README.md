## 本次改变了什么

### A/B：只改变时间，原画不变

原版 11 帧各 80 ms，共 880 ms。节奏版时长依次为 100、100、120、160、40、30、30、100、70、100、130 ms，共 **980 ms**：顶部多停留，击出快，最低点短停留，回肩放慢。这里没有画出碰撞目标，最低点停顿只是节奏假设。

同长基线采用前十帧 90 ms、末帧 80 ms，合计同为 980 ms，避免把“整体放慢”误判为节奏改进。逐帧像素对比确认节奏版 11 帧画面与旧 GIF 相同。调整时间没有修复旧画的手肘、回肩跳姿和转锤式路径。

### C：程序制作的固定骨长二维骨架

这是**重新制作的程序结构稿，不是 Computer Use 手绘，也没有运行 OpenToonz、Blender、RIFE 或 AI 生成模型**。用现有 Pillow 绘制刚性部件，解析式两节骨 IK 求肘/膝位置，双手目标放在同一刚性锤柄上。验证约束的价值，无需先安装新工具。

- 上臂/前臂各 58 单位，腿段 87/85；握点不可达时报错，不靠伸长肢体兜底。
- 锤柄 230 单位、握点间距 44；脚底固定；骨盆和上身随蓄力、击出移动。
- 按 25 fps 采样 65 张，2.6 秒；GIF 合并相同停帧后实际编码 45 帧，保留总时长。
- 起始和终止均为同一扛肩姿势，首尾像素完全一致；边界有静止段，避免从运动中硬接回待机。
- 收回沿反向弧线回肩，避免上一版近似整圈转锤。镜头固定并留足锤头范围。

这里的数值是模型坐标，输出镜头缩放为 0.82。验证误差小于 1e-12 单位。它说明长度和握点约束成立，**不说明人体运动学、力量传递或打击反馈已经合格**。

新版轮廓和握持关系比旧稿更容易读，首尾跳姿有明确修复。但当前身体偏刚、手臂仍会与躯干/武器重叠，头发是刚性片状，没有衣发跟随；没有人体关节角限制、碰撞目标或接触物理。它仍不是可交付的角色美术与战斗动画。

C 同时改变了画法、姿势、相机与时长，**不能用它证明某一单项改变的因果效果**。A/B 才是时间分配的控制对照；C 只验证骨架约束可以消除哪些几何漂移。没有人工标注评分或游戏内手感验收。

## 下一步取舍

补充调研支持优先使用二维骨骼/部件动画与少量关键姿势重画。OpenToonz Plastic 的定长、角度限制、道具挂接和曲线编辑是可用候选，但双手握持不是官方承诺一键解决。本机已有 Blender 的 IK 也可作为后续常规工具路线；无需为了验证这些原理先接大模型。

暂不批量做 RIFE/FILM/AnimeInterp 补帧：原画错误不会因插出更多画面消失，细线与交叉遮挡还可能增加断线/重影。优先下一次只精修扛肩、最大蓄力、击出三张关键姿势，再让中间段服从它们。

来源与硬件/许可边界见 [二维骨骼方案](../2d-rig-options-2026-09-21.md)、[补间方案](../inbetween-options-2026-09-21.md)。这些工具的兼容性与速度未在本轮实测，不将程序小样冒充软件运行结果。
