# 连续动画与建模选型汇总

本轮由动作调研、模型调研两路并行完成，另用 Computer Use 完成 11 帧挥锤粗线稿。仅调研与绘图，没有安装模型、下载权重或恢复 Unity 开发。

## 推荐决策

游戏继续横版 2D。3D 可用作离线动画支架：统一模型和骨架 → 动作与握持修正 → 固定正交镜头渲染 → 少量二维描修 → Unity 精灵序列。模型一致性避免每帧人物变形，但动作设计与清理成本仍存在。

| 项目 | 价值 | 主要边界 | 当前建议 |
|---|---|---|---|
| Kimodo | 文字、关键姿势、手脚/路径约束生成连续人体动作；SOMA BVH | NVIDIA 路线、Llama 访问授权；需重定向，锤子与长发另外制作 | 有 GPU 条件再试一段挥锤，不在 Mac 盲装 |
| image-to-3dlab | Apple Silicon 图片转贴图 GLB 的集成工作流 | 不是现成人形绑定管线；24GB 低于集成仓 32GB 推荐；整合代码许可待明确 | 模型阶段备用，先用简单人偶验证动作 |
| GEM-X | 视频恢复连续人体姿态，有官方 Mac ONNX/CoreML 路线 | 动捕误差与骨架转换仍需处理；机器人 BVH 不等同 Unity 人形 | 本机视频动捕首选调研候选，未实测 |
| Pixal3D Metal | 有作者 M5/24GB 低分辨率运行记录 | 作者数据非本机测量，生成网格仍需修整 | 若确需图转模型，先单后端小样 |
| UniRig / SkinTokens | 自动骨架和蒙皮 | CUDA 环境，不能保证手、衣服、长发权重正确 | 后置；不要先扩建研究环境 |

## 小样验收

只做同一段扛肩→蓄力→挥击→收回。简单人偶、独立长柄锤即可。看侧面轮廓、锤长、握点、脚滑、身体重心、命中节奏和回待机过渡。记录准备、运行和人工返修时间；若修正时间不比二维部件动画少，停止扩展该路线。

现有 11 帧粗稿证明可以把姿势按动作弧线组织起来，但没有解决手臂结构与打击重量感。不要将“可以连播”当作“已经有游戏动作质量”。
