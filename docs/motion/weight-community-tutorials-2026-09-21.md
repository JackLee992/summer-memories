# 力量感教程查证与本轮挥锤试验建议

核验日期：2026-09-21。范围是动画研究与独立素材试验，不恢复 Unity 玩法开发。以下正文已实际读取；没有把嵌入视频的标题当成已经看完的视频。来源是教学者的公开分享，本页的具体帧数是我们的试验方案，并非教程规定。

## 最值得马上应用的五篇

### 1. AnimSchool：Animating Weight

- 原文：<https://blog.animschool.edu/2025/05/02/animating-weight/>
- 讲师 Anthea Kerou 的公开课堂摘要，2025-05-02；已读取完整文字，未观看内嵌完整课堂视频。
- 原文要点：力量需要通过姿态可见；推动重物时脚向后蹬、躯干倾斜并改变重心。用“努力与结果的比例”判断重量——身体付出明显努力而物体只移动少量，容易被读成重物。需要改变尝试方式，而不是始终同一姿态匀速移动。
- 应用于挥锤：起锤和回收时先让身体撑住、压低，再让锤头缓慢离开原位置；下砸可以快，快慢反差应该来自不同阶段的工作。
- **原文限制**：文中一句 “Heavy objects fall faster” 作为一般物理命题不准确；忽略空气阻力时物体自由落体加速度相同。本试验不采用这句话，不用“物体越重所以必须掉得越快”来解释动作。

### 2. Animator Island：Remember the Weight

- 原文：<https://www.animatorisland.com/remember-the-weight/>
- J.K. Riki，2012-05-28；已读完整正文，包括 2D 与 3D 的区别。
- 原文要点：设立地平面帮助判断承重；从最终主视角先把姿态设计清楚，再用其他角度检查。两个物体坐标相接并不表示真正承重，脚要有承担体重的可见表现，而非只把坐标放到地上。
- 应用于挥锤：保留足底固定是必要条件，但加上前后支撑脚关系、膝盖弯曲、髋部前后转移。检查持锤剪影时，不能只靠后侧视角“技术上没有穿帮”。

### 3. Animator Island：Physics in Animation — Force and Momentum

- 原文：<https://www.animatorisland.com/physics-in-animation/>
- Alejandro Garcia，2015-08-10（2017-11-08 更新）；已读完整正文。
- 原文要点：力量表现为动量的改变，包括速度改变和方向改变。强冲击应有迅速的动量改变；同样冲击下较重物体反应较小。观察参考时，要追问什么力造成什么轨迹、速度变化，避免孤立地设计时间曲线。
- 应用于挥锤：给锤头一个明确的目标。命中前轨迹连续且逐步加速；接触时锤头迅速减速，身体和衣发继续产生受控制的跟随。不要只让手臂快速摆动却让身体保持原状，也不要用持续匀速圆周运动当一次打击。

### 4. Animator Island：Physics in Animation — Action-Reaction

- 原文：<https://www.animatorisland.com/physics-in-animation-action-reaction/>
- Alejandro Garcia，2016-11-29；已读完整正文。
- 原文要点：相互接触时，双方同时受力；打击者本身也需要被接触反力影响。原文举例：出拳者手部会被拳靶反力减速，只让受击者飞走而忽略打击者是常见错误；推石头时脚对地的作用必须和手部作用匹配。可以为了戏剧性违背物理，但应知道自己为何这么做。
- 应用于挥锤：锤头接触靶面、手臂屈曲、胸髋短暂压缩应构成一个受力事件；之后才是身体调整和回收。视觉“命中停顿”不等于让全身、头发、武器一起冻结很久。此处说的是动画接触表现，尚未接游戏 hitstop。

### 5. AnimSchool：Blocking Plus Workflow — Timing

- 原文：<https://blog.animschool.edu/2025/08/08/blocking-plus-workflow-timing/>
- 讲师 Jean-Luc Delhougne 的公开课堂摘要，2025-08-08；已读完整文字，未观看内嵌课堂视频。
- 原文要点：先做好关键姿态和姿态之间的空间关系，再调时间；蓄力常需比主动作停留更久让观众读清。落地后立即完全停止会缺少动量吸收，需要额外的步伐、重心调整或轻微回弹。快慢节奏有变化，避免关键帧等间隔导致机器感。
- 应用于挥锤：不要因为“更顺”把出击均匀补慢。先验收肩扛、后拉、发力、接触、卸力五个姿态，再把爆发压缩、把回收延长。首轮播放只看原速，不只看半速和静帧。

## 次级运动的补充阅读

- [Physics in Animation: Weight Gain and Loss](https://www.animatorisland.com/physics-in-animation-weight-gain-and-loss/)，Alejandro Garcia，2016-08-31（2016-11-23 更新）。已读完整正文。
- 原文把 Richard Williams 的 counteraction 和动画里的 drag 联系起来：头发、衣物、柔软部位应跟随加速度变化产生延迟，而不是只根据角色正在向上或向下来判断。快速上提重物时人物和物体的合成重心也更难平衡。
- 本轮应用建议：头部、发尾、衣摆可以晚于躯干启动和停止，但不要用无论主体怎样动都固定摆动的正弦曲线。重锤的惯性是主动作的一部分，衣发只是辅助。

## 可直接执行的一轮节奏

这是对现有 60 帧、20 fps 试验的建议，不是医学/武术指导，也不是已验收的游戏攻击时长。最终实际帧表应以新版脚本和导出视频为准。

| 帧段 | 动作任务 | 需要看到的变化 |
|---|---|---|
| 1–8 | 肩扛锤、观察目标 | 锤杆落在肩侧，手与脸留负空间，身体有承重偏移 |
| 9–20 | 拉开、蓄力 | 膝髋下降、躯干后拉，锤头迟一些跟上，锤与身体都不要穿越头部 |
| 21–24 | 支撑脚发力 | 髋胸先朝目标移动；锤头仍稍留在后方；视线已向目标 |
| 25–28 | 加速下砸 | 锤头弧线与手轨迹连贯，帧间距扩大；可以约 2 帧错开髋胸和锤，但以目视结果为准 |
| 29 | 接触 | 锤头真正接触指定靶面；停止向靶内穿透 |
| 30–34 | 吸收、短回弹 | 锤头保持接触或轻微反弹，膝髋继续压缩；胸肩与衣发的停止时刻不同 |
| 35–46 | 费力回收 | 回收明显慢于出击，先稳定身体，再收回锤；不要沿下砸轨迹完全倒放 |
| 47–60 | 回到肩扛 | 保留最后的稳定姿势，头发逐渐收束，首尾循环不跳位 |

本轮如果维持双手固定握点，可以先把动作受力做清楚；不应该为追求复杂度强行加换握。以后加入换握时，要明确哪只手持续承担武器、哪只手何时脱开/滑动/重新握住，并在重新抓握那一帧保证无空间跳变。上述已读材料没有给出重锤专用换握的完整分解，因此不声称换握方案已获来源验证。

## 对照验收

1. 关掉镜头抖动、残影、粒子和音效，正常速度仍能看出“蓄力→快砸→受阻→费力回收”。
2. 黑色剪影下仍能区分头、双臂、握点、锤头；肩扛锤不是锤子悬浮在背后。
3. 接触帧锤头落点与靶面吻合；下一帧不继续穿透，也不凭空弹回很远。
4. 脚滑动/腕部约束/循环首尾检查只能证明技术连续性，不能证明美术商业质量。
5. 正常速度、半速、接触附近逐帧都能查看，记录当前具体失败点，不把“补帧更顺”当成唯一目标。
