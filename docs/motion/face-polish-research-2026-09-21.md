# 二次元脸部与长发：针对当前挥锤角色的第二轮修形依据

日期：2026-09-21。已查看 `art-weight-trial-2026-09-21/frames/0001.png`，并读了当前 `build_study.py` 的脸、眼睛、眼镜、发壳、发束和材质代码。本轮只研究与提建议，未修改建模脚本，未下载或安装模型、贴图、插件。

当前长发、眼镜与西装已经可辨认。脸仍偏几何人偶：眼镜轮廓比眼神更强，面部正面较平，头发由几条独立长带构成。下一步最值得做的是**眼睑和虹膜关系 → 脸侧轮廓 → 头发整体体积 → 面部明暗稳定性**，不必重建全身。

## 三篇实际读过的资料

### 1. sawada / AnimeCGLab：先决定脸如何形成轮廓，而不是只加面数

[4 Categories of Face Topology in Anime 3D Model](https://animecglab.com/en/4-categories-of-face-topology-in-anime-3d-model/)，2023-01-09。HTTP 200，已读完整英文正文；没有把文章嵌入的商业模型拿来使用。

文章将脸的构造思路分成 Silhouette、Real、Deformed、Symbol 四类，明确这是作者的分类思路，并不是行业强制规范。与当前练习最相关的内容：

- **Silhouette type** 优先安排斜视时的脸颊轮廓；嘴周可较简洁，不必硬加写实法令纹。轮廓边与受光分区较易控制，但太锐的形体在连续渐变着色或脸部图案下可能显得别扭。
- **Real type** 的脸颊比较圆润，适合较写实的变形；用于 cel look 时，通常还要靠贴图/着色器设计阴影，不能期待写实拓扑自然产生动画的阴影形状。
- **Symbol type** 允许眼、眉、嘴作为独立部件，但需要处理它们与脸的结合和变形。独立眼睛并非“错误做法”，关键是转头后是否仍贴合。

**对应当前代码**：`Face_tapered_jaw` 是每圈椭圆截面的 loft，无法独立控制眉弓、脸颊前缘与眼窝；只增加 `n=32` 到更高面数，仍是同一种截面。更有效的是保留低面数、将前半圈顶点按高度和左右位置做有目的的偏移，形成浅眉弓、平顺脸颊和收窄下颌，再在正面/三分之四/侧面检查。

文章还引用了 X 上的面部拓扑讨论，但本轮只读取到博客里的嵌入文字；**没有核实 X 原帖完整内容或其图片**，不把它们另列成已学过的原帖。

### 2. Ascalon / aVersionOfReality：脸的几何轮廓与受光法线是两件需要分别设计的事

[A Custom Normals Workflow for Clean, Stylized Toon Shading](https://www.aversionofreality.com/blog/2022/4/21/custom-normals-workflow)，页面日期 2022-04-22。HTTP 200，已读完整正文；未观看视频。

作者解释了一个常见误判：toon 阴影边缘对拓扑和法线插值非常敏感。即使曲面很细，轻微不均匀的边间距也可能产生波浪状阴影；把模型越磨越圆，可能先毁掉脸的形状，却仍没有解决着色。

他的总体方法是分开处理：

1. 基础网格负责轮廓、变形和性能。
2. 更简单、光顺的代理形体提供主要法线。
3. 鼻、嘴、眉弓和眼睑等必要细节，以单独的法线细节加回。
4. 面部变形时，让代理/细节按需要响应；静止时干净的法线不保证表情变化后仍干净。

作者也说明：稀疏顶点的法线质量有限；烘焙法线、切线基准不一致会带来问题；文章是一个可验证的技术框架，并非任何脸套上就好看的成品按钮。2022 年原文对 Geometry Nodes 当时功能的描述不能直接当作 2026 年版本限制。

**对应当前代码**：当前脸只有 `Head` 一根骨骼权重，尚无嘴部/眼睑表情变形，所以本轮不需要先实现整套动态代理系统。可先把脸部顶点法线向一个干净椭球/简化面部的解析法线作有限混合，或用独立代理测试普通法线传递；必须保留鼻与轮廓附近的方向变化。只修改前脸局部，不把整颗头所有法线强行设为 `(0,-1,0)`。

若做解析法线，脚本中网格顶点经 `INV` 转进了骨架局部空间，**不能把世界坐标中的“脸朝前”直接写为网格局部法线**。应使用正确的法线空间变换并归一化；若存在非均匀缩放，需要逆转置关系。先验证当前 Blender 的 custom-normal API，再应用到完整头网格。

### 3. BlenderArtists 的真实迭代：眼睛“呆”不只在瞳孔，而在眼睑开口

[Critique a beginner's second stylized character?](https://blenderartists.org/t/critique-a-beginners-second-stylized-character/1576380)。作者 `never_stop_learning`，讨论从 2025-01-27 开始。已读取论坛 JSON 返回的帖子，针对性完整读了 #9、#18、#19，并查看 #18 的眼睛修改前后预览图；不是仅看帖子标题。

- [#9，MaylaMaker 的具体反馈](https://blenderartists.org/t/critique-a-beginners-second-stylized-character/1576380/9)：从三分之四角检查脸颊深度；侧视补清楚眉弓和嘴部；给眼睛加小高光；让眼睑覆盖虹膜上下部分，避免一直睁到最大的空瞪状态。
- [#18，作者实施](https://blenderartists.org/t/critique-a-beginners-second-stylized-character/1576380/18)：作者实际加了小圆形高光。因原本眼开口接近参考，最后选择拉长虹膜，使上下边缘不再完整露出，并反馈眼神更自然。这表明“缩眼开口”与“放大虹膜”应按实际画面选择，不是两项永远一起做。
- [#19，作者继续修法线](https://blenderartists.org/t/critique-a-beginners-second-stylized-character/1576380/19)：前脸法线偏朝前，鼻部法线稍向侧；但 Mirror 配合 Mark Sharp 导致 Line Art 在脸中央画出一条线，作者通过关闭 Line Art 的 Crease 类别绕开。这个坑有明确环境条件，当前脚本并未使用该线稿配置，不需要照搬修复。

这是一篇初学者持续迭代与社区反馈，不是专家发布的制作标准。引用其具体实验现象，不把其中所有人体比例结论当作通则。帖子后面展示过商业作品对比，本轮只查看作者自己的眼睛前后对比，不下载其中参考模型或媒体。

## 长发整体体积：当前代码应怎样改

补充核实了 BlenderArtists 的[发型方法讨论 #6](https://blenderartists.org/t/trying-to-make-a-game-compatible-hair-for-a-semi-realistic-character/1629940/6)，`sozap` 于 2026-02-07 说明：先建立代表头发体积的网格，再把它作为曲线/发片铺设的参考。该讨论主题是半写实发片，并不是二次元长发专课；我们只借用“先有整体体积”的方法，不把发片流程强行搬进本练习。上一轮已查看的 Xeofrios 多视角长发分享见 `character-art-tutorials-2026-09-21.md`。

当前 `ribbon()` 的截面只有四点，而且所有截面固定沿世界 X 展宽、Y 方向加厚；五条 `Hair_back_lock_*` 并排从头后延伸，容易读成独立布条。可在现有函数基础上作以下调整：

1. **先有共同的后发体**：用 5–7 个横向高度层构成从后脑、颈后到肩背的宽面，按高度改变宽度与深度。让头顶到后脑再到长发有连续外轮廓，底端再分叉；不要在后脑下缘直接分成五根相互分离的细带。
2. **覆上少量主发束**：保留现有长发束，但它们主要承担局部轮廓、搭接和不同长度的尖端。让大部分发束与后发体重叠，只有下段逐渐分开。这样无需增加几十根细发也能更厚实。
3. **截面跟随发束方向**：根据路径切线建立稳定局部截面轴，用 6–8 点扁椭圆/略带棱面的截面替代固定四点菱形。连续截面避免突然翻转。提高面数本身不是目的，是为了控制宽面和侧面厚度。
4. **统一大色块**：当前每隔一束切换 `hair_light`，容易形成等距条纹。让主体使用同一深色；高光只落在一个较连贯的大区，并随头部曲率变化。先靠外形、明暗方向分层，再加发丝纹理。
5. **共同摆动再局部错开**：后发体与主要长发束需要相近的根部固定区和摆动方向，尾端可稍错开；不要一个后发体不动、五个尖端大幅飞出。现有 `Tip_lag` 是手工位移形变，新增后发体也只能称为手工次级动作，不能称为碰撞模拟。

## 对 `build_study.py` 可直接执行的改动清单

下面参数是根据当前脚本尺寸制定的**初始试验范围**，并非来源作者数值，也不是已测试的结果。

| 优先级 | 当前对象/函数 | 明确修改 | 检查方式 |
|---|---|---|---|
| 1 | `Eye_white`、`Eye_iris`、`Upper_lid` | 保持眼白宽度，先将虹膜纵半径由 `.007` 试到 `.008–.009`，让上缘被上眼睑遮住；不要让整颗虹膜像珠子完整浮在眼白里。补一个很小、偏上侧的浅色高光 | 先去掉眼镜查看双眼，再戴回眼镜。正面与三分之四都应有明确注视方向，不能一眼看前方、一眼看侧面 |
| 1 | 上/下眼睑 | 用贴合脸表面的弧形带定义开口，上睑比下睑稍重；外眼角微上扬或平直以匹配冷静成人气质。当前圆管上眼线先保持细，避免像第二层镜框 | 近景确认眼白不穿出眼睑，再缩回 720 像素全身图；缩小时不应只剩黑圈 |
| 1 | `Glasses_frame` | 当前管半径 `.0032`；可在近景试 `.0022–.0026`，并缩小镜框与眼睛之间的距离，确保眉毛不与上框完全重叠。保留独立镜腿 | 双眼应透过镜框读得出来。缩细后不能在全身图彻底消失；由实际输出决定是否接受 |
| 2 | `Face_tapered_jaw` | 给前半圈顶点独立的眉弓、眼窝与脸颊偏移；三分之四时应读到脸颊前缘，侧面保持鼻—嘴—下巴的连贯层次。不要只把脸改成更尖的三角形 | 同一光照渲正面、侧面、三分之四头部图；再在第 18、29 帧看低头/仰头是否露出空隙 |
| 2 | `Nose`、`Mouth` | 将目前鼻子独立三角楔的根部与脸接合，减轻尖块感；嘴保留短线，先校正到脸表面，不用加厚嘴唇补“精细度” | 侧面鼻根不悬空、正面鼻阴影不变成大三角；嘴在斜视时不漂浮 |
| 2 | `Hair_scalp`、`Hair_back_lock_*` | 加连续后发体，保留少量覆盖发束与不齐尾端；头顶发际线过渡改平顺。取消每束交替亮色的规则 | 正、侧、后视都应看到共同体积，不能像头盔接几条带子；第 29/32 帧不出现明显根部断开 |
| 3 | 脸部材质 `skin` / 法线 | 单独给脸设置较温和的两档明暗；先观察纯几何平滑法线，再试局部代理/解析法线混合。不要把衣服全局 `.40/.73/1.0` 三档因子当作脸也必须使用的风格 | 同一脸固定相机、主光左右各转一点，观察阴影是否突跳、破碎；不能只在一个灯位看起来正确 |

如果时间只够一轮，优先做**眼睑/虹膜、减轻镜框遮挡、后发整体体积**，再出同机位前后对比。法线是解决阴影形状的工具，不会自动修正脸型、眼睛位置或头发剪影。
