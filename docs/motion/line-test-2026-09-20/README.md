# Computer Use 线稿试验

2026-09-21 更新。用户在开发暂停后单独授权绘图和调研，本试验不恢复游戏系统开发。

## 实际交付

- 在 Chrome 的 Piskel 中用直线工具通过 Computer Use 逐笔绘制 11 帧，512×512，两层（纸底、线稿）。屏幕坐标辅助规划姿势，未导入程序渲染人物。

## 结果与局限

扛肩→抬锤→挥出→跟随→回肩的顺序已经完整，锤子沿连续旋转方向运动，脚底位置基本固定。背景闪烁已消除，可以用来检查动作弧线。

**这仍是粗结构动作实验，未通过游戏素材质量验收。** 主要问题：手肘折线和手臂交叉不自然，身体体积与肢体长度未完全锁定，缺少有效蓄力/命中停顿，等时播放像转动锤子而非有重量的攻击；第 11 帧回到第 1 帧时手臂仍跳变。固定脚底也不等于有可信的重心转移。没有据此声称动作已经流畅或可投入游戏。

## 制作经验

先检查关键姿势和时间分配，再补中间帧；仅增加帧数无法修复重心和握持关系。Computer Use 逐笔绘制可验证方法，但大量重复笔画成本高，不适合批量生产人物素材。下一次小样优先用统一 2D 骨骼或简单 3D 人偶约束骨长、脚底和锤子握点，关键姿势保留人工修正；不继续无约束逐帧生成。

此前 Blender Grease Pencil 尝试未形成可用动画，Piskel 曾因电脑锁定中断；现已完成上述文件导出，旧的“一帧且未保存”状态失效。
