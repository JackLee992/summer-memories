# 阶段归档：横版原型、动作研究与 Seedance 试验

2026-09-21，所有者判断当前效果距离商业化仍有明显差距，要求先整理进度、提交并推送。本次保存已有工作，结束当前实验；游戏开发继续暂停。没有新增生成、下载安装、玩法修复或 Unity 构建。后续研究或开发须由所有者另行提出。

## 当前结论

**已经得到可保存、可编辑、可比较的机制与动画原型，还没有达到商业游戏或商业动画的交付水平。** 横版比 3D 更容易看见成果，但没有解决连续动作质量和低成本生产；AI 视频能提高画面细节，尚不能稳定保住角色比例、完整构图和动作时间，也不输出可回写游戏的网格与骨骼。

本次在 `codex/2-5d-squad` 分支归档。上一个已推送基线是 `fda23e5`（3D 小队 v03）；本次提交包含其后的 2.5D、横版、研究与动画试验。保存分支用于继续研究，不合并为可发布版本。

## 验证证据与边界

- 3D 旧基线报告：80 项；2.5D 2026-09-20 报告：94 项；横版旧报告：39 项。后两份已归档于 `docs/verification/`。
- 横版检查使用直接定位，部分战斗提高当前角色血量到 100。真实配置血量为 24/22/28，因此不能以 39 项报告证明普通玩家通关、难度合理或五分钟时长。2.5D 不是同一测试条件，不将血量提升限制泛化到该报告。
- **最新 C# 晚于旧包**：横版构建程序集为 18:22:40，部分 Session/World 为 18:23:34，HUD 为 18:25:38。旧包与报告不是当前源码完整快照。按此次仅归档和开发暂停的范围，未重新运行 Unity；提交不声称当前源码已编译/出包通过。
- Blender 最新 72 帧中，腕目标误差小于 0.001、踝目标误差小于 0.001 个场景米；13/61 帧切换位置及朝向差为 0，重新打开工程验证控制器可改。此为约束与编辑性证明，不是美术/表演验收。

## 距离商业化的主要差距

1. **美术与动画**：角色神态、拓扑/肩肘变形、头发和武器碰撞、手指细节、稳定轮廓、最终二维清稿都未达标。固定锚点和补帧不能代替关键姿势与表演。
2. **玩法验收**：普通血量全程、操作反馈、跳跃/战斗节奏、敌人对场景碰撞尚未完成；横版图集复用姿态，装备显示和逻辑不完全同步。
3. **数据与恢复语义**：横版还有硬编码坐标/阈值，配置校验不完整；存档主要按锚点恢复，不是完整当前位置/血量快照。与完整数据驱动目标有差距。
4. **制作成本与控制**：AI 输出仍需挑选和返工；这次 Seedance 细节更丰富，但比例、裁切和时机被改写。未建立“可预测成本下稳定生产可用资产”的流程。
5. **发行范围**：当前《夏日重现》角色/设定为同人原型，不声明原创；现有素材记录不等于商业发行授权，项目既有素材替换与许可政策继续适用。
